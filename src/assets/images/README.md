# Image assets

Shared raster artwork is exported from `index.ts`. The onboarding flow currently
uses `HAA Health.png` and `Labs, quick commerce and global commerce.png`.
Keep app icons and platform launch assets in the native Android and iOS asset
catalogs.

Recommended naming: lowercase kebab-case with `@2x` and `@3x` variants where
needed, for example `empty-state.png`, `empty-state@2x.png`, and
`empty-state@3x.png`.
